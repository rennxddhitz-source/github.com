# Bagian 2 — Core Loop & Fantasi Pemain

## Mikro (Detik–Menit)

Pemain mengawasi gerakan kereta di peta. Aksi: menahan/tahan kereta, mengalihkan jalur saat ada rintangan (longsor, hujan), memantau indikator bahan bakar (Bahan Bakar Turun per detik). Feedback: partikel asap berkurang, suara mesin berubah nada saat bahan bakar <20%.

## Meso (Menit–Jam)

Pelesaian kontrak delivery → mendapatkan Gold + XP → upgrade gerbong atau beli kereta baru → buka rute baru di wilayah selanjutnya. Keputusan menarik: pilih rute pendek dengan bayaran kecil tapi cepat, atau rute panjang dengan reward besar tapi risiko bahan bakar habis di tengah jalan.

## Makro (Jam–Hari)

Membangun jaringan lintas seluruh wilayah. Meningkatkan reputasi perusahaan. Menghapuskan "kereta legendaris" setelah menyelesaikan semua rute di 5 wilayah.

## Keputusan Menarik (Contoh)

| Keputusan | Opsi A | Opsi B | Konsekuensi |
|-----------|--------|--------|-------------|
| Rute delivery | Rute A: 80 km, 100 Gold, 2 menit | Rute B: 200 km, 300 Gold, 5 menit | A: cepat tapi sedikit untung. B: banyak untung tapi bahan bakar habis 40%. |
| Upgrade gerbong | Tambah kapasitas (+2 slot) | Kurangi konsumsi BB (-15%) | A: lebih banyak item per kali perjalanan. B: lebih hemat, rute panjang lebih aman. |

## Feedback Loop

Input pemain (jadwal rute) → Sistem menghitung waktu & konsumsi → Kereta berjalan → Pemain memantau → Delivery selesai → Gold dan XP masuk → Pemain upgrade → Loop ulang dengan rute lebih jauh.
